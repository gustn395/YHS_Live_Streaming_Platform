MediaMTX WebRTC POC

WHIP 송출과 WHEP 시청을 검증하는 페이지입니다. 절차와 결과 기록: docs/testing/poc-mediamtx-webrtc.md

페이지

  • PC 송출 — 화면 공유 + 마이크 + 화면 오디오 믹싱 (POC-02~04, 09)
  • 모바일 송출 — 전면·후면 카메라 + 마이크 (POC-06, 07, 09)
  • 시청: pc · 시청: mobile — WHEP 재생 (POC-05, 08, 10)

인증서

이 페이지는 Caddy 내부 CA가 발급한 인증서를 씁니다. 테스트 기기에서 경고 없이 쓰려면 루트 인증서를 내려받아 설치하고 신뢰해야 합니다.

루트 인증서 내려받기 (yhs-poc-caddy-root.crt)

설치 방법은 결과 문서의 "인증서 신뢰 절차"를 따릅니다. 주소창에 경고가 없으면 신뢰가 된 상태입니다.
