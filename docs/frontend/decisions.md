Backend `errors[]`는 비밀번호 길이 오류와 문맥 단어 오류를 구분하지 않으므로(같은 `field`, 코드 없음) 비밀번호 `errors[]` 오류는 비밀번호·username 둘 다에 의존한다고 보고, 유출 오류(`MEMBER_PASSWORD_BREACHED`)는 비밀번호에만 의존한다. 서버 오류 문구는 해석하지 않는다. | (1) 보이는 글자를 바꾸면 음성 입력 사용자가 부를 이름이 상태마다 달라지고, 이름과 상태가 겹쳐 "표시, 눌림" 같은 모순된 안내가 된다(WCAG 2.5.3, WAI-ARIA APG 토글 버튼). (2) 가입 화면에는 로그인 세션이 없어 권한 없음 화면이 도움이 되지 않고, 이동하면 입력값을 잃는다.
